# راصد المشتريات — إصدار مستقل من الصفر

برنامج ويب عربي متجاوب للجوال، مكتوب بـ HTML/CSS/JavaScript دون خادم أو مكتبات خارجية. لا يعتمد على كود برنامج `rasid-purchases` السابق.

## طريقة التشغيل
- من GitHub Pages: إعدادات المستودع → Pages → Deploy from a branch → main → / (root) → Save.
- الرابط بعد النشر: https://drburghash-sys.github.io/purchase-/
- أو افتح `index.html` محليًا في متصفح يدعم التخزين المحلي.

## الوظائف
- الرئيسية: إجمالي كافة الفواتير، مصروف الشهر الحالي، الرصيد المرحّل، ومتوسط الإنفاق.
- الفواتير: أرشيف غير مقيد بالشهر، بحث في المتاجر والأصناف، تعديل واستيراد.
- المقارنات: تاريخ أسعار المنتج بين جميع الأشهر، وأقل سعر بحسب المتجر، وإجمالي مشتريات كل متجر. مطابقة بالباركود أولًا أو بالاسم والعبوة بعد تطبيع بسيط.
- المصروف الشهري: جميع الأشهر أو شهر محدد، المتوسط التقويمي ومتوسط أشهر الشراء، والإنفاق لكل متجر.
- الإعدادات: مبلغ الميزانية الشهرية الثابت، نسخ JSON وCSV، واستعادة نسخة مع **دمج دون حذف**.

## احتساب الميزانية
يبدأ الحساب من أقدم شهر مسجّل إلى الشهر الحالي. لكل شهر:
`المتاح = الميزانية الشهرية الثابتة + رصيد الشهر الماضي`
`المتبقي = المتاح - المصروف الفعلي`
العجز السالب يُرحّل أيضًا؛ لا يختفي في الشهر التالي. تغيير الفلتر في صفحة المصروف لا يغير هذا التسلسل.

## بيانات البداية
البرنامج يحتوي على فاتورتين أوليتين في `seed.js` تُحمّلان **عند التشغيل الأول فقط**:
- 2026-10-27 — مؤسسة سالم محمد بن جحلان — الفاتورة 2641300055637 — 813.650 ريال — 35 بندًا. المجموع المستخرج للبنود 813.680 ريال، بفرق 0.030 ريال يحتاج مراجعة.
- 2026-11-03 — علي حافظ — الفاتورة 312744 — 274.040 ريال — 25 بندًا. اسم المتجر مأخوذ من شاشة البرنامج القديم ويحتاج التأكد، وأحد الأصناف غير واضح.

**تنبيه خصوصية:** المستودع عام، وملف `seed.js` منشور للعامة. إذا أردت أن تظل فواتيرك غير منشورة، احذف الملف من تاريخ المستودع العام واستخدم الاستيراد المحلي بدلًا من تضمين البيانات.

## حماية البيانات
- التخزين في مفتاح مستقل `rasid-clean-v2` داخل `localStorage` لهذا الموقع.
- تُحفظ لقطة سابقة قبل كل حفظ، ويمكن استعادتها من الإعدادات.
- زر نسخة احتياطية مباشر في أعلى الشاشة.
- استعادة نسخة JSON قديمة تدمج الفواتير الجديدة دون استبدال الموجودة.
- لا يقرأ هذا الموقع `localStorage` للموقع القديم لأنه يعمل على مسار مختلف (ولكنه على **النطاق نفسه** إذا كان العنوانان على drburghash-sys.github.io؛ مع ذلك مفتاح التخزين يختلف). سجل البداية مستقل، ويمكن استيراد نسخة من القديم.
- لا توجد مزامنة سحابية. مسح بيانات المتصفح قد يفقد التعديلات إن لم تُحفظ نسخة خارجية.

## الملفات
- `index.html`: هيكل الواجهة
- `style.css`: الهوية والتجاوب مع شاشات الهواتف
- `seed.js`: فواتير البداية الأولية
- `app.js`: الحسابات ولوحات المقارنة والميزانية
- `editor.js`: استيراد JSON، تصحيح الأصناف، الدمج والنسخ الاحتياطي
