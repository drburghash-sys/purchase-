# راصد المشتريات — الإدخال اليدوي الموحد

تطبيق عربي متجاوب للجوال يعمل بدون مكتبات خارجية، ويعتمد **إدخال كل عملية شراء يدويًا** بدل تصوير الفاتورة وإرسالها إلى ChatGPT.

الرابط عند تفعيل GitHub Pages: https://drburghash-sys.github.io/purchase-/

## خطوات إدخال شراء جديد
1. اختر **＋ شراء جديد**.
2. سيظهر التاريخ والوقت تلقائيًا بتوقيت السعودية، ويمكن تعديلهُما. أدخل اسم المتجر أو اختر متجرًا سابقًا، والفرع ورقم الفاتورة إن وُجدا.
3. اكتب جزءًا من اسم الصنف: تظهر مسميات الأصناف المسجلة سابقًا. اختر الاسم المعتمد، أو أدخل اسمًا جديدًا.
4. أدخل الكمية أو الوزن، وحدتها (حبة، عبوة، كجم، جرام، لتر، مل...) وسعر الوحدة. يحسب البرنامج إجمالي الصنف تلقائيًا، ويمكن تعديله كما في الفاتورة.
5. اضغط **إضافة الصنف ثم التالي**، وكرر للأصناف المتبقية. تظهر قائمة جميع الأصناف ويمكن تعديل أي سطر.
6. أدخل ضريبة الفاتورة وإجماليها (المجموع يكون شامل الضريبة، دون إضافتها مرتين)، ثم اضغط **حفظ الشراء كاملًا**. يستطيع زر الحفظ أيضًا إضافة الصنف الجاري إدخاله تلقائيًا.

## دليل الأصناف الثابت
- لكل صنف رقم داخلي ثابت `productId`، وتُحفظ مسمياته في `db.catalog`.
- عند اختيار الصنف لاحقًا، تُستخدم هويته نفسها في جميع المتاجر، وليس مجرد تطابق نص الاسم.
- قسم **الأصناف** يسمح بتعديل الاسم المعتمد أو دمج صنفين مختلفي الأسماء، مع بقاء تاريخ الفواتير وأسعارها دون حذف.
- تُنشأ مسميات أولية من الأصناف الموجودة في الفواتير القديمة عبر مطابقة الاسم حرفيًا بعد التطبيع، **دون دمج تخميني للمنتجات**. يمكن دمج الأسماء القديمة يدويًا مرة واحدة.
- تقارن الأسعار بالوحدة القابلة للمقارنة. تُحوّل الجرامات إلى كجم والملليلترات إلى لتر للمقارنة، دون تغيير المبالغ المسجلة في الفاتورة. لا يقارن البرنامج عبوة بسعر كيلو مباشرة.

## صفحات التطبيق
- **الرئيسية:** إجمالي جميع الفواتير والمصروف الحالي والرصيد المرحّل ومتوسط الشهور.
- **الفواتير:** أرشيف جميع المشتريات، وقت كل عملية، البحث والتحرير وتصدير فاتورة محددة.
- **المقارنات:** ترتيب المتاجر حسب أقل سعر من الفواتير، وإظهار جميع المتاجر المتساوية في المرتبة الأولى.
- **الأصناف:** قائمة المسميات المعتمدة وإعادة التسمية ودمج التاريخ.
- **المصروف الشهري:** شهر محدد أو جميع الشهور، والمتوسط والميزانية المرحّلة.
- **الإعدادات:** ميزانية شهرية أساسية، تصدير JSON وCSV واستعادة النسخ السابقة بالدمج.

## الأمان والبيانات السابقة
- يحتفظ البرنامج بجميع بياناته في `localStorage` تحت المفتاح القديم للإصدار الجديد `rasid-clean-v2` نفسه، فلا تبدأ قاعدة بيانات فارغة عند الترقية.
- تُحفظ مسودة الشراء أثناء الإدخال في مفتاح مستقل `rasid-manual-inprogress-v1`؛ عند العودة إلى «شراء جديد» يعرض إمكانية مواصلة المسودة.
- تُحفظ لقطة قبل الحفظ في `rasid-clean-v2-previous`، ويوجد زر **نسخة احتياطية** أعلى الشاشة.
- استيراد نسخ JSON من الإعدادات يدمج الفواتير دون استبدال الموجودة.
- النسخ الاحتياطية تحتوي أيضًا أسماء المنتجات وهوياتها الثابتة، وليست الفواتير فقط.
- لا توجد مزامنة سحابية تلقائية؛ لا تمسح بيانات المتصفح قبل تنزيل نسخة احتياطية.

## الفواتير الأولية
ملف `seed.js` في المستودع يتضمن فاتورتي أكتوبر 2026 (بن جحلان) ونوفمبر 2026 (علي حافظ) عند التشغيل الأول فحسب. فاتورة أكتوبر بها فرق سابق 0.030 ريال بين مجموع البنود وإجمالي الفاتورة ويحتاج للمراجعة.

**خصوصية:** المستودع عام، وبالتالي فواتير `seed.js` المنشورة مرئية للعموم. الفواتير اليدوية التي تضيفها من داخل المتصفح لا تُرفع إلى GitHub.

## ملفات المشروع
- `index.html`: بنية التطبيق
- `style.css`: تنسيق الشاشات الكبيرة والجوال
- `app.js`: دليل الأصناف والمقارنات والميزانية والأرشيف
- `editor.js`: إدخال يدوي خطوة بخطوة، حفظ المسودات، إدارة المسميات، وتصدير واستعادة البيانات
- `seed.js`: بيانات البداية الموثقة سابقًا
